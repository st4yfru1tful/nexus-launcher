# Nexus brand assets

`nexus-mark.svg` is the horizontal documentation wordmark. `nexus-icon.svg` is the square, vector-friendly source for executable and UI icons. Both are original, repository-owned Nexus Launcher artwork.

`scripts/Generate-BrandAssets.ps1` deterministically creates the multi-resolution Windows icon, 512-pixel logo, and branded cover fallback consumed by the WPF project. `nexus-ambient.png` is original project artwork generated for the 1.0 visual system and packaged as a low-contrast interface texture.

Do not replace it with logos, artwork, or visual identity copied from Steam, Xbox, Playnite, Discord, Spotify, or any other third party.
